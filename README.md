# Yemayá Demo

Demo comercial y SEO-first de Yemayá Restaurante Familiar para `yemaya.hacheinteractive.com`.

## Principios

- Mobile-first.
- Arquitectura SEO basada en Hache-Base.
- Fotografías reales del restaurante.
- El logotipo original de Yemayá se utiliza sin reinterpretación ni rediseño.
- Efectos CSS/JS sujetos a presupuesto de rendimiento y `prefers-reduced-motion`.

## Estado

Primera implementación visual y técnica en desarrollo.
